FEREZ Remote Desktop — ΠΡΩΤΗ ΕΚΔΟΣΗ ΚΩΔΙΚΑ / SOURCE PREVIEW

ΤΙ ΠΑΡΑΔΙΔΕΤΑΙ
Πηγαίος κώδικας RustDesk 1.4.9 μαζί με το hbb_common και τις πρώτες αλλαγές ονόματος.
Δεν περιέχει έτοιμο ή δοκιμασμένο Windows EXE. Δεν είναι τελική έκδοση v1.0.0.
Το λογότυπο και μεγάλο μέρος της εμφάνισης παραμένουν της αρχικής εφαρμογής.
Οι υπάρχουσες ελληνικές μεταφράσεις περιλαμβάνονται στον κώδικα.

ΕΠΟΜΕΝΟ ΒΗΜΑ: BUILD ΣΤΑ WINDOWS ΜΕΣΩ GITHUB ACTIONS
1. Δημιούργησε ένα ξεχωριστό repository για αυτό το project στον δικό σου λογαριασμό.
   Μην το ανεβάσεις μέσα στα Athlopolis ή Pegassos.
2. Ανέβασε ΟΛΑ τα περιεχόμενα αυτού του φακέλου στη ρίζα του repository,
   μαζί με τον φάκελο .github. Το ZIP ως συνημμένο δεν αρκεί.
3. Actions -> FEREZ Windows Preview -> Run workflow.
4. Αν πετύχει, κατέβασε το artifact FEREZ-Remote-Desktop-Preview-Windows-x64.
   Το προγραμματισμένο αποτέλεσμα είναι αυτοεξαγόμενο δοκιμαστικό EXE,
   όχι ξεχωριστός επαληθευμένος installer MSI.
5. Αν αποτύχει, στείλε το log του πρώτου αποτυχημένου βήματος.

Δεν εκτελέστηκε build ούτε ενεργοποιήθηκε υπηρεσία ή χρέωση από εδώ.
Έλεγξε τις παροχές Actions του λογαριασμού πριν ξεκινήσεις. Μην ενεργοποιήσεις
πληρωμένες επιπλέον χρήσεις. Δημόσιο repository σημαίνει δημόσιος κώδικας.
Το workflow εκκινείται μόνο χειροκίνητα και δεν δημοσιεύει release.

ΔΟΚΙΜΗ ΜΕΤΑ ΤΟ BUILD
- Αρχικά portable σε δύο δικά σου/εξουσιοδοτημένα PC χωρίς εγκατάσταση service.
- Κλείσε το κανονικό RustDesk πριν τη δοκιμή για να αποφύγεις διενέξεις.
- Έλεγξε ID, αποδοχή/απόρριψη αιτήματος, εικόνα, ποντίκι, πληκτρολόγιο,
  διακοπή συνεδρίας και μεταφορά ενός δοκιμαστικού αρχείου.
- Δοκίμασε από διαφορετικά δίκτυα, π.χ. το δεύτερο PC μέσω hotspot.
- Μην υποθέσεις ότι ο κωδικός/ID του RustDesk μεταφέρεται: το νέο όνομα
  αλλάζει και τη θέση ρυθμίσεων. Οι διαδρομές custom client θέλουν δοκιμή.
- Δεν έχουν επαληθευτεί UAC, υπηρεσία, εγκατάσταση, updates ή υπογραφές EXE.

ΥΠΟΔΟΜΗ
Ο κώδικας διατηρεί τις upstream προεπιλογές δικτύου. Αυτό ΔΕΝ επιβεβαιώνει
ότι οι δημόσιοι servers θα εξυπηρετούν το fork, ούτε εγγυάται δωρεάν
υποδομή για όλους. Απαιτείται ξεχωριστός έλεγχος πριν από δημόσια διανομή.
